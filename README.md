Welcome to my **CAD Design Portfolio**, a curated collection of mechanical engineering and robotics projects developed using **SolidWorks**.

This repository showcases my experience in:

- Mechanical Design

# Design Philosophy

My design approach emphasizes:

- Functionality before complexity
- Parametric and reusable CAD models
- Clean, maintainable assemblies
- Engineering documentation
- Manufacturability
- Continuous improvement through simulation and validation

Every project in this portfolio is developed with professional engineering practices in mind, balancing performance, practicality, and documentation quality.
