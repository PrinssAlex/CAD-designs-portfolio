# Project Overview

This project presents the complete mechanical design and assembly of a quadcopter unmanned aerial vehicle (UAV) created in SolidWorks.

The design demonstrates the application of parametric CAD modeling, mechanical assemblies, reusable components, engineering drawings, and animation to develop a lightweight aerial robotics platform. The project emphasizes clean modeling practices, modular design, and manufacturable mechanical components suitable for educational, research, and robotics applications.
